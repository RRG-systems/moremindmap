- **Lead generation + follow-up + nurture.** Generating opportunities is different from systematically following up and converting them.
- **Team-building doctrine.** Know the operator before designing the team; identify missing capabilities; build role clarity; use organizational design rather than simply adding people.
- **Financial planning.** Income targets, production math, expenses and cash flow should connect desired economics to required activity.
- **Continuous improvement.** Plans are hypotheses to be reviewed against execution and outcomes, not sacred documents.
- **Producer case studies.** Potentially useful as examples of multiple viable operating models if facts are verified before being treated as evidence.
