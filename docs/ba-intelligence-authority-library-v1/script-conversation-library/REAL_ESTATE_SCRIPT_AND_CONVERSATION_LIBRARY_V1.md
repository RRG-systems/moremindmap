# Real Estate Script and Conversation Library V1

Version: `1.0.0`  
Status: `FROZEN_GOVERNED_RESOURCE_V1`  
Script families: `31`

Scripts are intelligence resources, never mandatory customer wording. The library governs objective, stage, conversational mechanism, permission, discovery, qualification, value, next action, response logic, follow-up, manipulation risk, personalization and provenance. Current law, brokerage policy, representation disclosure, calling/text/email consent and platform rules are Dynamic Research.

## SC-01 — Relationship qualification / referral permission

- **Objective:** Create an honest next step appropriate to `new/warm relationship` without forcing a transaction.
- **Stage:** new/warm relationship.
- **Underlying mechanism:** Permission, reciprocal context and a direct non-coercive mindshare question.
- **Opening / permission:** State identity and context plainly; ask whether now is an acceptable time or whether the topic is useful.
- **Discovery:** Ask a small number of open questions about situation, goal, timing, prior experience and what matters; listen before offering.
- **Qualification:** Distinguish need, readiness, authority/representation, fit and next horizon. Record unknown rather than manufacture urgency.
- **Value:** Offer only value supported by the agent’s authority and current evidence: interpretation, process clarity, relevant market/property information or connection to a licensed specialist.
- **CTA:** Agree one proportionate action, owner and date: conversation, consultation, resource, introduction, follow-up, nurture or respectful close.
- **Objections:** Clarify the real concern; acknowledge it; test whether it is information, trust, timing, economics, authority or fit; answer only within evidence and licensing boundaries.
- **Response logic:** If ready and fit, advance. If interested but not ready, nurture with permission. If not fit or not interested, archive/close respectfully. If regulated expertise is needed, refer.
- **Follow-up:** Reference the actual conversation, preserve consent/preferences, record next action and stop when permission is absent.
- **Manipulation risks:** Manufactured scarcity, fear, false familiarity, hidden purpose, relentless cadence, scripted empathy, unsupported market/financial claims, disclosure of another customer’s information.
- **Personalization variables:** Relationship state, source, role, goal, timing, communication preference, property/area, prior interaction, relevant BOS communication considerations, language/access needs.
- **Provenance:** D.J. qualification/referral call; founder doctrine.
- **D.J. variant:** Preserve available D.J. wording as an optional founder variant when source text exists; never present it as mandatory wording or validated superiority.
- **External variants:** May be retrieved as current practitioner/official/primary evidence and kept source-labeled; they do not overwrite this mechanism.
- **Context-fit note:** Choose/adapt only after relationship state, legal/representation constraints, source, readiness and business objective are known.
