Unsupported claims remain explicit `Insufficient Evidence`, including future bottleneck, wrong-seat risk, inputs, operating loop, outputs, evolution path, risk, energy, environment, role fit, and future cards. One Move remains bound to its supplied Layer 2 claim and evidence boundary.

Stored approved images remain visible, but a Layer 3 overlay marks them `stored_visual_not_translated`. The customer UI explicitly states that embedded image text was not rewritten or revalidated by current customer intelligence. Stored legacy artwork is therefore not silently represented as current translated truth.
