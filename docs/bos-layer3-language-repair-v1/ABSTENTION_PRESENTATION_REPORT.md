# Abstention Presentation Report

Layer 2 abstentions remain machine-readable and unchanged. Layer 3 changes only their customer presentation:

- duplicate unsupported claim surfaces are omitted from the translation packet;
- one unsupported domain produces one concise limitation entry;
- a fully unsupported customer tab is omitted rather than filled with refusal cards;
- no raw `Insufficient Evidence` wall is used as default customer copy;
- renderer capability remains in place and automatically returns when the corresponding Layer 2 claim becomes sufficient.

Focused tests prove sparse input produces a usable two-tab view with consolidated limitations, while supported panels reappear without a hard-coded global removal.
