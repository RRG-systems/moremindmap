# Score Surface Repair Report

When Layer 3 is active, each score surface presents its recognizable everyday pattern first. The visible score, label, classification, and rank remain unchanged.

The repair removes redundant customer sentences equivalent to “You scored X” and “That is a Y score” when the interface already presents those facts. It no longer duplicates practical-use copy under two labels or turns an evidence boundary into a personalized weakness. Optional observation guidance is rendered once as “What to notice.”

The exact Layer 2 score rendering remains the deterministic fallback whenever Layer 3 is disabled, unavailable, rejected, or times out.
