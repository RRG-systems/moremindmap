# Visual DNA Conditional Rendering Report

The technical Visual DNA model is preserved. Layer 3 adds a customer-presentation projection that controls visibility from existing Layer 2 sufficiency and abstention contracts.

Always retained when available:

- measured score topology;
- dimension names and exact scores;
- primary and secondary emphasis;
- a concise recognizable summary;
- One Move as a hypothesis;
- one global plain-language limitation.

Unsupported future, team, environment, role-fit, energy, operating-loop, tension, evolution, input, output, advantage, and risk panels are conditionally omitted. Tests prove a supported panel automatically returns when its claim becomes sufficient. No technical Visual DNA field is deleted or rewritten.
